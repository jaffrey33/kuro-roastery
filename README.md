# Kuro Roastery ☕

A modern coffee roastery website designed to showcase the brand, its coffee offerings, and its visual identity through a clean and responsive web experience.

🔗 **Live Demo:** [Kuro Roastery](https://kuro-roastery.vercel.app/)
📦 **GitHub Repository:** [jaffrey33/kuro-roastery](https://github.com/jaffrey33/kuro-roastery)

## Overview

Kuro Roastery is a web development project focused on creating an engaging online presence for a coffee brand. The website uses a modern interface and responsive design to provide visitors with a smooth browsing experience across desktop and mobile devices.

## Features

* **Modern UI** — Clean and visually appealing website design.
* **Responsive Layout** — Designed to adapt to different screen sizes.
* **Reusable Components** — Organized components for maintainable development.
* **Optimized Performance** — Built with Next.js for a modern web experience.
* **Deployment** — Hosted on Vercel for public access.

## Tech Stack

* **Next.js** — React framework
* **React** — User interface library
* **TypeScript** — Type-safe development
* **CSS** — Website styling
* **ESLint** — Code quality and linting
* **Vercel** — Deployment and hosting

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have installed:

* [Node.js](https://nodejs.org/)
* npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/jaffrey33/kuro-roastery.git
   ```

2. Navigate to the project directory:

   ```bash
   cd kuro-roastery
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open http://localhost:3000 in your browser.
